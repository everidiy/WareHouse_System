# Warehouse System — Система управления складом

Консольное приложение для управления складскими товарами, разработанное на C#. Проект создан для практического изучения объектно-ориентированного программирования и принципов организации кода.

## 🛠 Используемые технологии

- **C#** — основной язык программирования.
- **.NET** — платформа для разработки приложения.
- **ООП** — объектно-ориентированное программирование.
- **MVP-подобная архитектура** — разделение логики, отображения и обработки действий пользователя.

## ✨ Возможности

- Просмотр списка товаров на складе.
- Добавление товаров на склад.
- Удаление товаров со склада.
- Отображение информации о товарах.
- Работа с различными типами товаров.
- Обработка пользовательского ввода.
- Управление складом через консольное меню.

## 📦 Типы товаров

В проекте используется базовый класс `Product` и производные классы, представляющие разные виды товаров.

| Класс | Описание |
|---|---|
| `Product` | Базовый класс для товаров |
| `Laptop` | Товар типа «Ноутбук» |
| `Phone` | Товар типа «Телефон» |
| `Headphones` | Товар типа «Наушники» |

Общие характеристики товаров:

- `Name` — название товара.
- `Type` — тип товара.
- `Price` — цена товара.
- `Quantity` — количество товара на складе.

Для отображения информации о товарах используется метод `ShowInfo()`.

## 🏗 Архитектура проекта

Проект организован с разделением обязанностей между основными компонентами.

| Класс | Назначение |
|---|---|
| `Warehouse` | Хранение товаров и управление складскими операциями |
| `WarehouseView` | Отображение меню, информации о товарах и сообщений |
| `WarehouseControls` | Обработка действий пользователя и управление взаимодействием компонентов |
| `Product` | Базовая модель товара |
| `Laptop`, `Phone`, `Headphones` | Производные классы товаров |

Для управления складом предусмотрены методы `AddProduct()` и `RemoveProduct()`.

Коллекция `Products` предоставляется для чтения через `IReadOnlyList<Product>`, что позволяет ограничить прямое изменение списка товаров извне класса `Warehouse`.

## 🚀 Запуск проекта

### Требования

- Visual Studio или другая совместимая среда разработки.
- Подходящая версия .NET SDK.

### Установка и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/everidiy/WareHouse_System
   ```

2. Откройте файл решения `.sln` в Visual Studio.

3. Соберите проект.

4. Запустите приложение и используйте консольное меню для взаимодействия со складом.
